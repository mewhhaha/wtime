# Rust host suspension policy

Host callbacks run synchronously. `Caller<'a>` lends mutable Store access only for that callback, and registered callbacks must be `Send + Sync + 'static`. A callback may invoke a guest function recursively. Guest continuation frames, operands and prompts are owned records; suspension never captures native Rust frames.

`create_host_func_with_outcome` permits forwarding an owned `RunOutcome::Suspended` produced by a guest invocation. Direct host invocation checks tag affinity, payload types, continuation liveness and compatible canonical signatures before publishing its payload and continuation as roots. Returning Suspended from a host callback called by an active guest frame returns Host error: that outer guest stack and native callback frames cannot be captured by this synchronous protocol. The embedding can root the continuation, resume it once, cancel it with `drop_continuation`, or release ownership and collect it. Ordinary value-returning callbacks cannot return a suspension outcome. Caller and borrowed Store state cannot escape into the owned outcome or registered callback; Rust rejects that unsupported borrowed capture at compilation. There is no native-frame capture operation or borrowed resumable host token, and therefore no runtime error branch for such an operation. Guest consumed/null continuation use traps; exhausted capture storage returns ResourceLimit before transfer.

Evidence: `t146_host_suspension_forward_validates_capability_and_payload` and `t146_guest_call_rejects_host_suspension_without_capturing_outer_frames` verify direct forwarding and rejected nested forwarding. `t040_nested_host_to_guest_preserves_ordered_results`, owned unhandled suspension tests in `continuation.rs`, `t147_repeated_suspension_release_and_cancel_do_not_retain_segments`, and the actual-engine T142 interaction test cover reentry, resumable guest state, prompt/EH preservation and cleanup. This is embedding policy, not an additional normative Core rule. JavaScript/browser host protocols remain outside scope.
