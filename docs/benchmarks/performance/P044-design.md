# Bounded canonical prefixes

P044 admits a straight-line integer/local/numeric direct-call prefix when the
existing whole-function Compact certificate declines. Reference parameters and
locals stay in the existing `Value` storage, with the existing frame roots.
The first control, memory or complex operation is the permanent decoded exit.
The original validated operation executes once in the same loop, after the
common source boundary has charged it. No program counter or effect is replayed.
Pure whole-function Compact candidates retain their existing certificates.

P113 supplies six freshly encoded and validated workloads and the identical
production harness for both sides. P114–P120 separately verify the certificate,
handoff and proposal interactions. The combined P044 gate keeps all P022 cases,
full runtime checks, paired performance and default/optional build budgets.
The targeted families and held-out controls are declared in P044-contract.json
before runtime edits. Timing has instrumentation disabled; diagnostics are
separate Rust checks. Unsupported entry cases must report zero prefix work.

The core stays dependency-free and safe Rust; Compact remains opt-in unless a
later portfolio gate supplies sufficient evidence for a policy change. A
rejected speed gate does not erase a passing semantic check or become a claim
that Compact should be selected by default.
