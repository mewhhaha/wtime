## 2. Goal, Scope & Explicit Stage 1 Admission Contract (`--backend x64`)

Build a self-contained pure-Rust (`#![forbid(unsafe_code)]`) Wasm → **Linux x86-64 SysV LP64** ELF64 `.so` compiler inside `tools/wtime-aot/src/x64/`:
- **Dependencies**: the compiler crate (`tools/wtime-aot`) depends only on in-tree `wtime-validate` and `wtime-types` (zero third-party crates, zero `clang`/`rustc`/`ld.lld` subprocesses); the **generated `.so`** has zero `DT_NEEDED`, zero dynamic relocations, and zero `libc` dependency (uses direct Linux x86-64 `syscall` for `mmap`/`mprotect`/`munmap`).
- **Metering, tracing, & safety policy**: `tools/wtime-aot` is an explicit opt-in AOT tool isolated outside the production safe-Rust core (`crates/*`, which remains metered with fuel and cancellation). `--backend x64` executes unmetered for `pen run` builds. In Pen (`crates/blot-host/src/lib.rs`), `engine_allows_aot(engine)` (`!engine.get_epoch_interruption() && !engine.get_consume_fuel()`) is enforced at **BOTH** compilation (`GuestModule::new_with_aot`) **AND** instantiation (`Guest::start`); `GuestModule::traced` compiles unconditionally through Wasmtime (`new_wasmtime`) so `SystemTrace` is never silently dropped under `PEN_WTIME_AOT=1`; and `Guest::set_deadline` panics explicitly if called on an `AotGuest`.

### 2.1 Target Platform (Linux x86-64 LP64), ISA Policy, & Runtime CPUID Gate
- **Supported target envelope**: **Linux x86-64 SysV LP64 ONLY** (`all(target_os = "linux", target_arch = "x86_64", target_pointer_width = "64")`, explicitly excluding Linux x32 ILP32 where pointers/`size_t` are 32-bit). Both `tools/wtime-aot` and Pen (`resolved_x64_isa_tag`) reject unsupported OS/arch/pointer-width hosts **before** any cache lookup (including for named CPU profiles like `x86-64-v3`).
- **Baseline required ISA (always emitted)**: Linux x86-64 LP64 + SSE2 + SSE4.1 (`roundss`/`roundsd`, `pextrq`/`pinsrq`) + POPCNT.
- **Optional ISA (`TargetIsa { has_abm_bmi1: bool }`)**:
  - Threaded explicitly into `lower::lower_ir_to_x64`.
  - When `has_abm_bmi1 == true`: `i32/i64.{clz,ctz}` emit single-instruction `lzcnt`/`tzcnt`.
  - When `has_abm_bmi1 == false`: `lower.rs` emits branchless portable `bsr`/`bsf` + `cmovz` (`63^31=32` / `127^63=64` for `clz`, `32`/`64` for `ctz`).
- **Single canonical CPU-to-profile mapping** (shared identically between `tools/wtime-aot/src/build.rs` and Pen `crates/blot-host/src/wtime_aot.rs::resolved_x64_isa_tag`; `x64-v2` and `x64-v3` are **internal compiler feature profiles**, not full psABI ISA levels):
  - `native` (default): `#[cfg(all(target_os = "linux", target_arch = "x86_64", target_pointer_width = "64"))]` checks `std::is_x86_feature_detected!("lzcnt") && std::is_x86_feature_detected!("bmi1")` -> `x64-v3` (`has_abm_bmi1 = true`) else `x64-v2` (`has_abm_bmi1 = false`).
  - `x86-64-v2` | `generic`: `x64-v2` (`has_abm_bmi1 = false`).
  - `x86-64-v3` | `x86-64-v4` | `znver<digits>` (strictly `"znver"` + non-empty ASCII digits, e.g. `znver1`..`znver5`) | `haswell` | `broadwell` | `skylake` | `skylake-avx512` | `cascadelake` | `cooperlake` | `cannonlake` | `icelake-client` | `icelake-server` | `tigerlake` | `rocketlake` | `alderlake` | `raptorlake` | `sapphirerapids` | `emeraldrapids` | `graniterapids`: `x64-v3` (`has_abm_bmi1 = true`).
  - Any other `--target-cpu` / `PEN_WTIME_AOT_TARGET_CPU` value: **rejected with an explicit error**.
  - **Cache key**: `build.rs` and Pen's fast cache key artifacts by the **resolved internal profile** (`x64-v2` vs `x64-v3`), never raw `"native"`.
- **Mandatory `blot_aot_new` CPUID check** (executed on host stack AFTER saving SysV callee-saved `Rbx` AND live entry arguments; Linux `ARCH_SET_CPUID` faulting is unsupported on production guest threads):
  1. `eax = 0; cpuid` -> require `eax >= 1`; if `has_abm_bmi1`, also require `eax >= 7`.
  2. `eax = 1; cpuid` -> require `ECX` bit 19 (SSE4.1) AND bit 23 (POPCNT).
  3. If `has_abm_bmi1`:
     - `eax = 0x8000_0000; cpuid` -> require **unsigned** `eax >= 0x8000_0001` (`cmp eax, 0x8000_0001; jb .unsupported_isa`, NEVER signed `jl` because bit 31 is set!).
     - `eax = 0x8000_0001; cpuid` -> require `ECX` bit 5 (ABM / LZCNT).
     - `eax = 7; ecx = 0; cpuid` -> require `EBX` bit 3 (BMI1 / TZCNT).
  4. On any missing feature: restore callee-saved regs, write `*trap_out = TRAP_UNSUPPORTED_ISA (22)` (if non-null), and return `NULL`; `blot_aot_trap_message(22)` returns `"Unsupported CPU ISA"`.

## 3. Exact ABI, Runtime Stack, Memory & ELF64 Specification

### 3.1 Register Partition & Unified Internal Wasm ABI
- **Pinned registers** (never allocated by regalloc; invariant across internal Wasm calls):
  - `Rsp`: active guest stack pointer (16-byte aligned before every `call`, so `rsp % 16 == 8` on callee entry)
  - `R15`: `Ctx*` (`BlotHandle == Ctx`)
  - `R14`: `mem_base` (fixed virtual `mmap` base — invariant across `memory.grow`; `NULL` if 0 capacity)
  - `R13`: `mem_len` (current accessible byte length — updated in-place by `memory.grow` after `mprotect` succeeds)
  - `R12`: pinned hottest mutable non-const `I32`/`I64` global (typically `$__stack_pointer`), synced with `Ctx` at every C ABI boundary, host callback, and active reentrant call/trap
- **Scratch registers** (never allocated by regalloc; strictly disjoint roles):
  - `R11` / `Xmm15`: primary scratch, internal trap return (`R11d = 0 | 1..22`), parallel-move **cycle-breaking** temporary
  - `R10` / `Xmm14`: secondary scratch, parallel-move **memory-to-memory copy** temporary
- **Allocatable registers**:
  - 9 GP: caller-saved `Rax, Rcx, Rdx, Rsi, Rdi, R8, R9` (7) + callee-saved `Rbx, Rbp` (2)
  - 14 XMM: `Xmm0..Xmm13` (caller-saved in Stage 1)
- **Unified Typed Internal Call ABI** (single source of truth in `regalloc::{layout_args, layout_rets}`):
  - GP args: `Rdi, Rsi, Rdx, Rcx, R8, R9`; FP/V128 args: `Xmm0..Xmm7`; overflow args on caller `[rsp + off]` (8-byte aligned scalars, 16-byte aligned 16-byte `V128`, total rounded to 16 B).
  - GP results: `Rax, Rdx, Rcx, Rsi, Rdi, R8, R9`; FP/V128 results: `Xmm0..Xmm7`; overflow results written to caller-owned 16-byte-aligned stack buffer `[rsp + ret_buf_off]` whose address caller stores into `[r15 + OFF_RET_SPILL_PTR]` immediately before `call`. Any callee with overflow returns saves `[r15 + OFF_RET_SPILL_PTR]` in its own frame slot `saved_ret_ptr_off` in its prologue and writes overflow results before `emit_parallel_moves` writes register results.
- **`I32` & narrow-global zero-extension invariant**: every `I32` SSA value in a GP register (including `R12` when `pinned_global` has type `I32`) has zero upper 32 bits, and every `I32`/`F32` global read/write across C boundaries uses exact 32-bit zero-extended loads/stores:
  - All 32-bit x86-64 ops and `mov_rr(false, d, d)`;
  - C ABI entry wrappers (`mov edi, esi` / `mov edi, arg_bits_lo`);
  - `HELPER_MEM_GROW` failure returns `mov eax, -1` (`0x0000_0000_ffff_ffff`, NOT `-1i64`);
  - All 8 `I32` `HELPER_TRUNC_BASE` routines produce 32-bit zero-extended `Rax` (`mov eax, eax` / 32-bit `cvtt*2si eax`);
  - `wt_import{k}` trampolines zero-extend `[I32]` results (`mov eax, eax`);
  - `blot_aot_get_global`, `blot_aot_active_get_global`, `blot_aot_set_global`, `wt_initialize`, `HELPER_HOST_CALL`, and all call wrappers use 32-bit zero-extended loads (`mov eax, [r15 + off]`, `mov r12d, [r15 + off]`) and 32-bit stores (`mov [r15 + off], edi` / `mov [r15 + off], r12d`) for `I32`/`F32` globals.

### 3.2 Dedicated `mmap` Guest Stack, SysV Alignment, Signals, & Reentry Protocol (Without `libc`)
`blot_aot_new` allocates a dedicated **8 MiB** guest stack with a **64 KiB `PROT_NONE` bottom guard** (anonymous demand-paged: unused pages consume zero physical RSS):
- Allocation: `mmap(NULL, 64 KiB + 8 MiB, PROT_NONE, MAP_PRIVATE | MAP_ANONYMOUS | MAP_NORESERVE, -1, 0)` followed by `mprotect(stack_base + 64 KiB, 8 MiB, PROT_READ | PROT_WRITE)`. On failure, save trap byte, `munmap` any prior allocations, and return `TRAP_ALLOC_FAILED (12)`.
- `stack_top = stack_base + 64 KiB + 8 MiB` (16-byte aligned).
- `stack_floor = stack_base + 64 KiB + 128 KiB` (**128 KiB headroom** above the `PROT_NONE` guard, leaving `8 MiB - 128 KiB = 7.875 MiB` usable guest stack).
- **Explicit non-overlapping signal headroom budget (strictly `< 128 KiB`)**:
  - Guest runtime reserve: SysV red zone (`128 B`) + internal helper frame (`<= 256 B`; Stage 2 `HELPER_HOST_CALL` `128 B`) + Stage 2 max elided subtree (`<= 8 KiB`) = **`<= 8.5 KiB`**.
  - Async signal reserve: supports up to **2 nested async signals** on the guest stack (`2 × (AT_MINSIGSTKSZ <= 16 KiB kernel xstate frame + <= 32 KiB handler frame) = 96 KiB`); combined worst case `8.5 + 96 = 104.5 KiB < 128 KiB` (**23.5 KiB safety margin**).
  - **Hard host contract**: Pen installs NO custom async signal handlers on `pen run` guest threads (only Rust's standard `SIGSEGV` altstack). Any embedder/thread installing async signal handlers with `> 2` nesting levels, `> 32 KiB` handler frames, OR running on CPUs where `AT_MINSIGSTKSZ > 16 KiB` MUST configure `SA_ONSTACK` + `sigaltstack` on calling threads (documented at `AotGuest::start`).
- **Concurrency, lifetime, destruction, & unwind preconditions**:
  - A `*mut Ctx` handle requires serialized access; concurrent calls on the same handle are UB.
  - **Idle-handle requirement for destruction/unloading**: `blot_aot_drop(h)` and `dlclose` require an **idle handle (`ctx->in_call == 0`)**. Calling `blot_aot_drop` from inside a host callback is an ABI violation; as defense-in-depth, `blot_aot_drop` checks `ctx->in_call == 0` BEFORE unmapping and returns as a no-op if `in_call != 0` so a buggy callback cannot unmap its own suspended stack/Ctx mid-flight!
  - **Legal callback-time APIs & borrowed memory lifetimes**: inside `host_fn(user_ctx, ac, ...)`, `*mut ActiveCall ac` is valid ONLY for the dynamic extent of that single `host_fn` invocation; the ONLY legal callback-time exports are `blot_aot_active_mem_data`, `blot_aot_active_allocate`, `blot_aot_active_reset`, `blot_aot_active_get_global`, `blot_aot_trap_message`, `blot_aot_abi_version`, `blot_aot_import_count`, and `blot_aot_import_name`. Any memory pointer/len observed via `active_mem_data` is invalidated across `active_allocate`, `active_reset`, or any guest `memory.grow` (re-query `active_mem_data` after every reentrant call!).
  - **No cross-frame unwinding**: C++ exceptions, Rust panic unwind, and `longjmp` across generated native frames are prohibited. Pen's `host_callback_trampoline` catches Rust panics via `std::panic::catch_unwind`, records `pending_panic`, returns `1` cleanly through generated frames, poisons the guest (`disposed = true`), and calls `std::panic::resume_unwind` on the Rust host side.
  - **Bounded callback reentry (x64 resource policy)**: Pen's `host_callback_trampoline` uses a short-locked `Mutex<AotHostState>` (NEVER held across `callback(...)` or `active_allocate(...)`) and restores `active.callback` before encoding array results, matching Wasmtime when guest `blot:allocate` invokes the active callback during result encoding (verified by `allocator_can_invoke_active_callback_during_result_encoding` under both Wasmtime and `PEN_WTIME_AOT=1`). As an explicit **x64 resource policy** to bound real host stack growth across `host_fn -> blot_aot_active_* -> wt_import -> host_fn`, x64 caps synchronous reentry at **`MAX_ACTIVE_REENTRY_DEPTH = 16`** (`ctx->active_depth: u32`); Wasmtime has no explicit 16-level callback quota, so at the 17th nested `active_*` call x64 deterministically returns `1` (`TRAP_CALL_STACK = 8`) while Wasmtime continues until stack exhaustion.
- **One exact SysV alignment & stack-switching recipe per wrapper**:
  - On entry to any SysV C export, `rsp % 16 == 8`. Pushing the 6 SysV callee-saved GP regs (`Rbx, Rbp, R12..R15` = `48 B`) leaves `rsp % 16 == 8`. Every wrapper allocates an **`8 mod 16`** local frame so **`rsp % 16 == 0`** at `ctx->host_rsp`!
  1. **`blot_aot_new` (`sub rsp, 56`, `rsp % 16 == 0`, zero slot reuse)**:
     - `[rsp+0]=host_mxcsr`, `[rsp+8]=user_ctx`, `[rsp+16]=host_fn`, `[rsp+24]=mem_limit_pages`, `[rsp+32]=trap_out`, `[rsp+40]=saved_trap_byte`, `[rsp+48]=pad`.
     - Save host `MXCSR` at `[rsp+0]`, run CPUID gate (§2.1), allocate `Ctx`, guest stack, and linear memory (§3.4), set `ctx->in_call = 1`, `ctx->host_rsp = rsp` (`% 16 == 0`), save host `rsp` into `[stack_top - 8]`, set `rsp = stack_top - 16` (`% 16 == 0`), load Wasm `MXCSR` (`0x1f80`), load `R15=ctx, R14=mem_base, R13=mem_len`, and `call wt_initialize`.
     - Inside `wt_initialize` (entered with `rsp % 16 == 8`): (1) write all non-folded global initializers into `Ctx`; (2) **then** load `R12 = ctx->g_pinned` (32-bit zero-ext for `I32`, 64-bit for `I64`); (3) check all active element bounds (`TRAP_TABLE_OOB = 3`); (4) copy all active data segments in declaration order, checking `(off as u64) + (len as u64) > R13 -> TRAP_OOB (2)` **FIRST** before skipping `len == 0` so 0-length OOB traps and 0-capacity `R14 == NULL` is never dereferenced; (5) if `module.start` is `Some(start_idx)` (defined OR imported `wt_import{k}` via `RelocTarget::Func(start_idx)`), `sub rsp, 8; call start; add rsp, 8; ret`, else `xor r11d, r11d; ret`!
     - Back on host stack: store `R12 -> ctx->g_pinned`, clear `ctx->in_call = 0`, restore host `MXCSR` (`ldmxcsr [rsp + 0]`). **On failure (`R11d != 0`): store `R11b` into `[rsp + 40]` BEFORE invoking `munmap` syscalls** (since `syscall` clobbers `Rcx`/`R11`), `munmap` guest stack, linear memory (if non-zero), and `Ctx`, write saved trap byte from `[rsp + 40]` to `*trap_out` (if non-null), `add rsp, 56`, pop callee-saved regs, return `NULL`.
  2. **Top-level call wrappers (`blot_aot_call_export`, `blot_aot_call_allocate`, `blot_aot_call_reset`, `blot_aot_call_finish_invocation`; `sub rsp, 40`, `rsp % 16 == 0`)**:
     - Exact precedence BEFORE touching guest stack or `MXCSR`:
       - Fixed-export wrappers (`allocate`/`reset`/`finish_invocation`): (a) missing/incompatible export -> return `3` (outs untouched); (b) `h == NULL` or `ctx->in_call != 0` -> write `*trap_out = TRAP_HOST (19)` (if non-null), leave `*res_out` untouched, return `2`.
       - `blot_aot_call_export`: (a) `h == NULL` -> return `3` (outs untouched); (b) `ctx->in_call != 0` -> write `*trap_out = TRAP_HOST (19)` (if non-null), leave `*res_out` untouched, return `2`; (c) `(np == NULL && nl > 0)` or unknown/incompatible export name -> return `3` (outs untouched).
     - Push `Rbx, Rbp, R12..R15` (`48 B`), `sub rsp, 40` (`rsp % 16 == 0`: `[rsp+0]=host_mxcsr`, `[rsp+8]=res_out`, `[rsp+16]=trap_out`, `[rsp+24]=h`, `[rsp+32]=pad`), save host `MXCSR`, set `ctx->in_call = 1`, load `0x1f80`, load `R15=ctx, R14=mem_base, R13=mem_len, R12=g_pinned` (width-exact), store `ctx->host_rsp = rsp`, save host `rsp` into `[stack_top - 8]`, set `rsp = stack_top - 16`, marshal arg (`mov edi, esi` / zero-ext narrow `I32`/`F32`), `call target`, restore `rsp = [stack_top - 8]`.
     - Back on host stack: store `R12 -> ctx->g_pinned` (normal AND trap), clear `ctx->in_call = 0`, restore host `MXCSR`, write `*res_out` ONLY on `R11d == 0` (`u64` zero-ext for `call_export`, `i32` for `call_{allocate,reset,finish_invocation}`) OR `*trap_out = R11b` on `R11d != 0`, `add rsp, 40`, pop callee-saved regs, return `0` / `1` / `2` (`R11d == TRAP_HOST` -> `2`, else `1`).
  3. **Host callback (`wt_import{k}` -> `HELPER_HOST_CALL`) — single unified recipe**:
     - Every `wt_import{k}` (entered `rsp % 16 == 8`) marshals all 9 admitted Blot import signatures (`module.rs:209-229`) into `(Edi = k, Rsi = tok, Rdx = arg_bits)` BEFORE calling `HELPER_HOST_CALL`:
       - `[]`: `xor esi, esi; xor edx, edx`
       - `[Ref]`: `mov rsi, rdi; xor edx, edx`
       - `[I32]`: `mov edx, edi; xor esi, esi`
       - `[F32]`: `movd edx, xmm0; xor esi, esi`
       - `[Ref, I32]`: `mov edx, esi; mov rsi, rdi`
       - `[Ref, I64]` / `[Ref, Ref]`: `mov rdx, rsi; mov rsi, rdi`
       - `[Ref, F32]`: `movd edx, xmm0; mov rsi, rdi`
       - `[Ref, F64]`: `movq rdx, xmm0; mov rsi, rdi`
       - Then set `mov edi, k` LAST, align `sub rsp, 8` (`rsp % 16 == 0`), `call HELPER_HOST_CALL`, convert result (`mov eax, eax` for `[I32]`, `movd xmm0, eax` for `[F32]`, `movq xmm0, rax` for `[F64]`), `add rsp, 8`, `ret`.
     - Inside `HELPER_HOST_CALL` (entered `rsp % 16 == 8`):
       - Check `cmp qword [r15 + OFF_HOST_FN], 0; je .trap_host` -> return `R11d = TRAP_HOST (19)` (matching `cgen.rs:4086`).
       - On guest stack: Stage 1 allocates **`sub rsp, 24`** (`8 + 24 = 32 % 16 == 0`: `[rsp+0]=prev_active_guest_rsp, [rsp+8]=prev_host_rsp, [rsp+16]=pad`; Stage 2 expands to `sub rsp, 120` = `24 + 96` for `Xmm8..Xmm13`); save previous `OFF_ACTIVE_GUEST_RSP` and `OFF_HOST_RSP`, store current `guest_rsp` into `[r15 + OFF_ACTIVE_GUEST_RSP]`; publish `R12` to `ctx->g_pinned` (width-exact).
       - Marshal callback args in registers **BEFORE** switching `rsp` (`mov r8, rdx; mov rcx, rsi; mov edx, edi` — never reading saved args off `[rsp + ...]` after switching stacks!).
       - Switch `rsp = [r15 + OFF_HOST_RSP]` (`rsp % 16 == 0`), execute `ldmxcsr [rsp + 0]`, `sub rsp, 32` (`rsp % 16 == 0` before `call`), build `ActiveCall { ctx = R15, mem = R14 }` at `[rsp + 0..16]` and `u64 res = 0` at `[rsp + 16..24]`, finish SysV 6-arg setup (`Rdi = [r15 + OFF_HOST_USER_CTX]`, `Rsi = lea [rsp + 0]`, `R9 = lea [rsp + 16]`; `Edx`/`Rcx`/`R8` already loaded), and `call qword [r15 + OFF_HOST_FN]`.
       - Capture `res = [rsp + 16]` and `eax` status, switch `rsp` back to `[r15 + OFF_ACTIVE_GUEST_RSP]`, reload `0x1f80` `MXCSR`, reload `R13 = ctx->mem_len` and `R12 = ctx->g_pinned` (width-exact), restore saved `OFF_ACTIVE_GUEST_RSP` and `OFF_HOST_RSP` from `[rsp+0]`/`[rsp+8]`, `add rsp, 24` (Stage 2: `120`), return `Rax = res` and `R11d = 0 | TRAP_HOST (19)`.
  4. **Active reentrant call (`blot_aot_active_allocate`, `blot_aot_active_reset`; `sub rsp, 40`, `rsp % 16 == 0`)**:
     - Exact precedence: (a) missing/incompatible export -> return `3`; (b) `ac == NULL` or `ac->ctx == NULL` or `ctx->in_call == 0` -> write `*trap_out = TRAP_HOST (19)` (if non-null), leave `*res_out` untouched, return `2`; (c) `ctx->active_depth >= 16` or wrap-proof bounds check fails (`suspended < ctx->stack_floor + 64 || suspended > ctx->guest_stack_top - 16`, guaranteeing `new_guest_rsp` never overlaps the outer wrapper's saved host `rsp` at `[guest_stack_top - 8]`) -> write `*trap_out = TRAP_CALL_STACK (8)` (if non-null), leave `*res_out` untouched, return `1`.
     - Push `Rbx, Rbp, R12..R15`, `sub rsp, 40` (`rsp % 16 == 0`), save host `MXCSR` at `[rsp+0]` + `res_out`/`trap_out`, **explicitly reload `R15 = [rdi + 0]` (`ac->ctx`) AND `R14 = [rdi + 8]` (`ac->mem`)** (SysV allows the Rust/C callback to repurpose `R14`/`R15` before calling back in!), compute `new_guest_rsp = (suspended & !15) - 32` (`>= stack_floor` and `% 16 == 0`), save previous `ctx->host_rsp` and current host `rsp` in that 32-byte link record, increment `ctx->active_depth += 1`, set `ctx->host_rsp = host_rsp`, load `R13 = ctx->mem_len`, `R12 = ctx->g_pinned` (width-exact), load `0x1f80`, switch `rsp = new_guest_rsp`, zero-ext `arg` (`mov edi, esi`), `call blot:allocate/reset`, restore `ctx->host_rsp` and host `rsp`, decrement `ctx->active_depth -= 1`, store `R12 -> ctx->g_pinned` (normal AND trap), restore host `MXCSR`, write 32-bit `*res_out` ONLY on `R11d == 0`, `add rsp, 40`, pop callee-saved regs, return `0`/`1`/`2`.
  5. **Wrap-proof pre-prologue function check** (`lower.rs:1728-1744`): `mov r11, [r15 + OFF_STACK_FLOOR]; add r11, (frame_size + 8*callee_saves); cmp rsp, r11; jb .early_stack_trap` (before any push, traps `TRAP_CALL_STACK = 8`).
  6. **`blot_aot_drop`**: if `h == NULL` or `ctx->in_call != 0`, return (no-op); else `munmap` guest stack (`64 KiB + 8 MiB`), guest memory (`mem_reserve_bytes`, if non-zero), and `Ctx` (`handle_alloc_bytes`).

### 3.3 `Ctx` (`BlotHandle`) Byte-for-Byte Layout
Every non-folded global (`global_consts[k].is_none()`) gets a checked `i32` slot at `global_offs[k]` (bounded by `MAX_CTX_BYTES = 16 MiB`):

|---:|---:|---|---|
| `0` | 8 | `mem_base: *mut u8` | Fixed virtual reservation base (`NULL` if 0 capacity) |
| `8` | 8 | `mem_len: usize` | Current accessible byte length (`pages * 65536`) |
| `16` | 8 | `mem_max_pages: u64` | Clamped max pages (`<= 65536`) |
| `24` | 8 | `mem_reserve_bytes: usize` | Exact reservation passed to `munmap` (`0` if no reservation) |

### 3.4 Memory Lifecycle & Linux Syscall Rules
- Linux syscalls use `(rax=nr, rdi, rsi, rdx, r10, r8, r9)`, clobber `rcx` & `r11`, and signal errors when `(rax as u64) >= (-4095i64 as u64)`. Keep syscall setup strictly isolated from SysV C call wrappers.
- **`blot_aot_new` memory limits** (exact match to `cgen.rs:4350-4355` and Pen `wtime_aot.rs`):
  - If module has **no memory**: `mem_base = NULL, mem_len = 0, mem_max_pages = 0, mem_reserve_bytes = 0` (no memory `mmap`).
  - If module has memory `(mem_min, declared_max)`:
    - `limit = if mem_limit_pages == 0 { 65_536 } else { mem_limit_pages }` (`0` means unlimited in library protocol v1; Pen enforces sub-page limits `< 64 KiB` on growable memories BEFORE calling `blot_aot_new` so `start` never runs and `memory.grow` cannot bypass a sub-page sandbox cap).
    - If `mem_min > limit`: fail with `TRAP_MEM_LIMIT (11)`.
    - `max_p = min(declared_max, limit, 65_536)`.
    - If `mem_min > max_p`: fail with `TRAP_MEM_TOO_LARGE (9)`.
    - If `max_p == 0` (genuine zero-capacity memory): `mem_base = NULL, mem_len = 0, mem_max_pages = 0, mem_reserve_bytes = 0`.
    - Else: `mmap(NULL, max_p * 65536, PROT_NONE, MAP_PRIVATE | MAP_ANONYMOUS | MAP_NORESERVE, -1, 0)`; if `mem_min > 0`, `mprotect(mem_base, mem_min * 65536, PROT_READ | PROT_WRITE)`. `mprotect` errors cleanly return `TRAP_ALLOC_FAILED (12)` (in `new`, unmapping all prior allocations) or `-1` (in `grow`, leaving `mem_len` unchanged).
- **`memory.grow` vs `blot_aot_mem_grow`**:
  - Shared `grow_core` reads `mem_base` from `[r15 + OFF_MEM_BASE]` (leaving `R14` untouched!), checks `delta == 0` (returns `old_pages` immediately without `mprotect`), checks `delta <= max_pages && old_pages <= max_pages - delta`, runs `mprotect(mem_base + old_len, delta * 65536, PROT_READ | PROT_WRITE)`, and updates `ctx->mem_len` & `R13` **only after `mprotect` succeeds**.
  - `HELPER_MEM_GROW` (Wasm `memory.grow`, `Rdi = u32 delta`): returns zero-extended `0xffff_ffffu64` (`mov eax, -1`) on failure, or `old_pages` in `Eax` on success.
  - `blot_aot_mem_grow(h, delta: u64) -> i64`: returns `-1i64` immediately if `h == NULL` or `ctx->in_call != 0` (defensive guard against illegal callback-time calls); pushes SysV callee-saved `R13, R15` (`16 B`, leaving `rsp % 16 == 8`), aligns `sub rsp, 8` (`rsp % 16 == 0`), loads `R15 = h, R13 = [r15 + OFF_MEM_LEN]`, calls `grow_core` with full 64-bit `Rdi = delta` (never truncating to `u32`), `add rsp, 8`, pops `R15, R13`, returns `old_pages as i64` or `-1i64`.

### 3.5 Exact Trap Codes, Helpers, & Complete 18-Export Library Protocol v1 (Blot Guest ABI 8)
- **Canonical Trap Codes `1..=22`** (matching `cgen.rs:134-157, 4275-4295` verbatim + x64 extension `22`):
  - `1`: `TRAP_UNREACHABLE` (`"Trap: unreachable"`)
  - `2`: `TRAP_OOB` (`"Trap: out of bounds"`)
  - `3`: `TRAP_TABLE_OOB` (`"Trap: table out of bounds"`)
  - `4`: `TRAP_INDIRECT_CALL` (`"Trap: indirect call type mismatch"`)
  - `5`: `TRAP_DIV_ZERO` (`"Trap: integer divide by zero"`)
  - `6`: `TRAP_INT_OVERFLOW` (`"Trap: integer overflow"`)
  - `7`: `TRAP_INVALID_CONV` (`"Trap: invalid integer conversion"`)
  - `8`: `TRAP_CALL_STACK` (`"ResourceLimit: call depth exhausted"`)
  - `9`: `TRAP_MEM_TOO_LARGE` (`"ResourceLimit: memory too large"`)
  - `10`: `TRAP_MEM_ALLOC_OVERFLOW` (`"ResourceLimit: memory allocation overflow"`)
  - `11`: `TRAP_MEM_LIMIT` (`"ResourceLimit: memory limit"`)
  - `12`: `TRAP_ALLOC_FAILED` (`"ResourceLimit: memory allocation failed"`)
  - `13..=18`: start/host-adapter codes (`cgen.rs:4287-4292` verbatim)
  - `19`: `TRAP_HOST` (`"Host: host failure"`)
  - `20`: `TRAP_EXIT` (`"program exit"`)
  - `21`: `TRAP_STOP_ITER` (`"Host: generator raised StopIteration"`)
  - `22`: `TRAP_UNSUPPORTED_ISA` (`"Unsupported CPU ISA"`, x64 extension)
- **Pure-guest helpers (`regalloc::HelperKind`)** preserve `Rbx, Rbp, R12..R15` (except `MemGrow` updating `R13`) and **all `Xmm0..Xmm13`**:
  - `HELPER_TRUNC_BASE + 0..15` (`HelperKind::Trunc`): `Xmm15 -> Rax` (32-bit zero-extended for `I32`, 64-bit for `I64`), `R11d = 0 | 6 | 7`; clobbers ONLY `Rax, R10, R11, Xmm14, Xmm15` (`gp_mask = MASK_RAX, xmm_mask = 0`).
  - `HELPER_MEM_GROW (16)` (`HelperKind::MemGrow`): `Rdi (u32) -> Rax (u32 zero-extended)`; clobbers `MASK_GP_CALLER, xmm_mask = 0`.
  - `HELPER_MEM_COPY (17)` & `HELPER_MEM_FILL (18)`: `(Rdi, Rsi, Rdx) -> R11d = 0 | TRAP_OOB`. **Mandatory zero-length OOB & null-`R14` order**: perform 64-bit unsigned bounds checks (`(dst as u64) + (len as u64) > R13` and for copy `(src as u64) + (len as u64) > R13`) **FIRST** (trapping `TRAP_OOB = 2` even when `len == 0` if `off > mem_len`), **THEN** early-return `R11d = 0` on `len == 0` **BEFORE** dereferencing `R14` (`NULL` for 0-capacity memories); overlap-safe forward (`rep movsb`) / backward loop using **unsigned non-zero countdown (`dec rcx; jnz`)** (never signed `jns`, so copies `>= 2 GiB` in a 4 GiB memory never exit early; no `std`/`cld`); clobbers `MASK_GP_CALLER, xmm_mask = 0`.
- **Six explicit behavioral differences vs `cgen.rs`** (all covered by Stage 1 C-vs-x64 differential tests):
  1. Trap code `22` (`"Unsupported CPU ISA"`) added for the CPUID gate.
  2. 0-capacity memories report `mem_base = NULL, mem_len = 0` (vs C's 1-byte static dummy).
  3. `blot_aot_import_name` and `blot_aot_trap_message` emit explicit `(ptr, len)` pairs pointing to non-null `.rodata` addresses even for empty strings (no `strlen` NUL truncation).
  4. Folded `RefNull` global exports return `(val = 0, kind = 4)` in `blot_aot_get_global`/`active_get_global` (`cgen.rs:4486` omits it).
  5. Top-level wrappers enforce `in_call == 0`, `blot_aot_drop` refuses to unmap while `in_call != 0`, and `active_*` enforces `in_call != 0 && active_depth < 16` (`cgen.rs:4386` lacks reentry/drop guards).
  6. Guest FP environment explicitly enforces Wasm default `MXCSR = 0x1f80` (round-to-nearest-even, no FTZ/DAZ) and restores host `MXCSR` on every return, trap, and host callback (`cgen.rs` inherits host `MXCSR`).

## 5. Stage 2 — Runtime Optimization Hill-Climb (Dependency-Ordered & Numerically Gated)

### 5.1 Pass Ordering & Enforceable Legality Rules
Every pass is evaluated independently against an **archived immediate predecessor** (per `task-plans/performance/EXECUTION.md`: phase compile cost + paired 5-workload `opt-palm` runtime + exact parity) before combining into the Stage 2 candidate. **`verify_ir`** (recomputing CFG predecessors independently, verifying SSA dominance, block-param arity/types, effect-summary soundness, and bounds-proof dominance) runs after EVERY CFG-changing pass, and **`verify_alloc`** (physical register/spill disjointness, edge copies, spill widths, helper clobbers) runs after regalloc in test builds.
1. **Profile Stage 1 first**: measure compile-time tail on `gdev-dev` and hot functions/spills/bounds-check cost on `opt-palm`.
2. **Budgeted small-leaf inlining on IR** (runs **first** so all downstream passes optimize inlined bodies): non-recursive hot helpers (`<= 45` insns, bounded total code growth, keeping original functions for indirect/exported callers). *Resource-trap depth policy*: inlining may legally shift the recursion depth at which `TRAP_CALL_STACK (8)` fires (a resource-limit trap, which can change observable partial side effects prior to stack exhaustion), so stack-exhaustion tests verify `TRAP_CALL_STACK (8)` fires cleanly before any guard fault without corrupting host state (if exact logical depth parity is ever required, retain an explicit logical depth counter).
3. **CFG rebuild & verification -> true dominator tree (`Cooper–Harvey–Kennedy`) & interprocedural effect analysis**:
   - **Enforceable invalidation rules**:
     - `GlobalGet(g)` facts are invalidated by `GlobalSet(g)`, any `Call` whose transitive callee may write `g` OR invoke a host import (`wt_import` -> `active_*` / `set_global`), any `CallIndirect`, and any loop header whose body may modify `g` (conservatively merged at CFG joins and loop backedges).
     - `MemLen` / bounds facts are invalidated by `MemGrow`, any `Call` that may transitively grow memory OR invoke a host import (`active_allocate`), any `CallIndirect`, and loop backedges containing any of the above.
     - `TableGet(t, idx)` facts are invalidated by `TableSet(t, ...)`, any `Call` whose transitive callee may write `t` OR invoke a host import (`wt_import` -> `active_*`), any `CallIndirect`, and any loop header whose body may write `t` (via any of the above).
4. **Dominator GVN / CSE + redundant `GlobalGet` elimination + conservative LICM**:
   - **Memory alias, write, trap, & progress rules**: GVN/CSE on `Load` requires proof that NO intervening `Store`, `MemCopy`, `MemFill`, `MemGrow`, `Call` (that may write memory or invoke a host import), or `CallIndirect` exists on any path from the dominating `Load` (and for `TableGet(t, idx)` CSE, a dominating `TableGet(t, idx)` already proved `idx < tlen` with no invalidating effect between them). LICM MUST NEVER hoist ANY potentially trapping instruction (`Load`, `Div`, `Trunc`, `TableGet`, `BoundsCheck`) out of a potentially zero-trip loop or across an earlier observable effect or earlier trap; and DCE/LICM MUST NEVER eliminate a potentially non-terminating loop (progress preservation).
5. **Loop & cross-block bounds-check elimination + wrap-safe addressing-mode folding**:
   - Dominator `checked_max` propagation & counted-loop induction-variable range hoisting ONLY with formal proof that (a) zero-trip loops cannot turn an unexecuted body into a hoisted trap, (b) no earlier store/global-write/call/trap can be misordered relative to the hoisted trap, and (c) any rewritten bounds check covers the **exact same `[eff_addr, eff_addr + access_bytes)` byte interval** as the original Wasm address calculation.
   - **Wrap-safe addressing-mode folding**: explicitly distinguish wrapping 32-bit Wasm arithmetic (`i32.add`/`i32.shl` mod `2^32`) from non-wrapping 64-bit `MemArg.offset` (`(addr as u64) + (offset as u64)`). Because x86-64 SIB accepts at most 2 registers (`base + idx*scale + disp`) and ModRM `disp32` is **signed `i32`**, when `r14`, `base`, and `idx` are all independent, precompute one sum (`addr = base + idx*scale` or `r14 + base`) FIRST; and ONLY fold Wasm `i32.add`/`i32.shl` into a 64-bit effective address when a range/induction proof establishes BOTH NO 32-bit unsigned wrap (`(base as u64) + (idx as u64)*scale + (disp as u64) < 2^32`) AND **signed-`disp32` encoding fit (`0 <= disp <= i32::MAX as u64`)** (materializing larger displacements in a register as Stage 1 `lower.rs:342` already does)!
   - *(Signal-based `SIGSEGV` guard-page bounds elimination is quarantined as a separate exploratory research branch **outside** Stage 2 promotion until fault-PC classification tables and host `SIGSEGV` signal chaining have their own dedicated safety contract.)*
6. **SSA cleanup (DCE/copy-prop) -> Register coalescing & ABI/loop-phi hinting + loop-depth weighted regalloc** + **callee-saved `Xmm8..Xmm13`**:
   - Internal convention preserved by generated callees; `regalloc.rs`'s final `frame_size` includes `16 * saved_xmm` bytes (so `early_stack_trap` covers them automatically without double-counting).
   - Inside `HELPER_HOST_CALL` (entered with `rsp % 16 == 8`), expand Stage 1's `sub rsp, 24` to **`sub rsp, 120`** (`24 B` saved links/pad + `96 B` for `Xmm8..Xmm13` at `[rsp + 0..96]` via `movaps`/`movdqu`; `8 + 120 = 128 % 16 == 0`, preserving exact 16-byte guest-frame alignment — total `128 B` well below the 128 KiB floor headroom!).
7. **Cheap instruction-selection peepholes**:
   - `Cmp + Select -> cmp + cmovcc` (handling unordered FP `PF` cleanly); skip `CmpBranch` fusion across intervening `Call`/`CallIndirect`.
   - Constant signed/unsigned `div`/`rem` -> magic multiply + shift (preserving exact divide-by-zero & `INT_MIN / -1` trap semantics).
   - Inline small constant-length `memory.copy` / `memory.fill` (`<= 64 B`) with widened bounds check before any write, preserving overlap and `len == 0` OOB semantics.
   - Memory-operand ALU (`add/sub/cmp r, [rsp+spill]`) and `xorps d, d` false-dependency break before scalar `cvtsi2s*`/`round*`/`sqrt*` when `d != ar`.
8. **2-phase native-frame stack-check elision -> THEN direct-call trap-check elision** (strictly coupled order!):
   - **Step 8a (Stack-check elision)**: parallel (SSA + regalloc producing final `frame_size` which already includes `16 * saved_xmm`) -> sequential acyclic max-native-frame propagation computing each candidate's **exact worst-case transitive native stack use**: `final_frame_size + 8*saved_gp + 8 /*ret addr*/ + max(callee_subtree_bytes, max_helper_frame_bytes)`. A function's prologue check may ONLY be elided if:
     1. It is **NOT** exported, **NOT** `start`, and **NOT** referenced in any `call_indirect` table (so `wt_initialize`, top-level wrappers, `blot_aot_active_*`, and `call_indirect` NEVER enter an unchecked callee directly!);
     2. It is non-recursive and calls **ONLY** other elided callees or pure helpers (NEVER retaining callees, `wt_import`/`HELPER_HOST_CALL`, or `call_indirect`, so no unbudgeted return address can ever push below `stack_floor`);
     3. Its exact subtree native stack use is `<= 8 KiB` (explicitly budgeted in §3.2's 128 KiB floor reserve); AND
     4. Every retaining caller's prologue stack check reserves `final_frame_size + 8*saved_gp + max_elided_subtree_bytes` (including helper frames & return addresses on every retained incoming edge!) against `stack_floor`!
   - **Step 8b (Direct-call trap-check elision)**: runs strictly **after** Step 8a; a callee qualifies for `!fn_can_trap` ONLY if `!callee.needs_stack_check` AND it has zero trapping Wasm ops and zero trapping callees in its transitive call graph (keeping full `R11d` trap ABI for indirect, exported, and unchecked entrypoints).
