## Input/output contract

Version-2 workload entries contain id, deterministic source/generator, typed params/results, oracle, required features, work units, reset policy, stages and comparator capability. Named selections are explicit lists, not inferred from a directory.

## Implementation recipe

1. Extract existing MVP entries without changing their generated bytes or scalar adapter; define selections original-mvp, scalar, memory, simd, gc-exceptions, continuations, threads, representative and integration.
2. Add typed JSON value adapters for i32/i64/f32_bits/f64_bits/v128_bits and normalized reference categories; keep payload setup and result validation outside timed intervals where the stage permits.
3. For each comparator run a compile/execute capability probe with explicitly enabled Wasmtime features; record unsupported proposal cases as wtime-only with the reason and prohibit ratios for them.
4. Validate unique IDs, input bounds, deterministic hashes, stage/reset compatibility and independent oracle registration before process launch; expose candidate-mode parsing only after P016.
5. Keep typed workload setup/protocol conversions compatible with the original public API in the frozen-core adapter. Rebuild only the adapter under a new harness hash for new workloads; reject incompatible modes/features, preserve frozen sources and record original-vs-adapter binary identities.

## Meaningful cases

- An unsupported continuation comparator has no fabricated Wasmtime row.
- Duplicate IDs, missing oracle or incompatible stage/reset policy fail validation.
- Float bit patterns and V128 byte order survive serialization; original MVP hashes are unchanged.
